      🎵 Music

      MIDI mode

      A per-channel band (between the lyrics and controls) with volume, mute/solo and live levels for the current MIDI song. MIDI songs only.

      Key detection

      Reads each song's key from the MIDI. Shown as current → transposed beside the title, and drives auto-tune's "Auto" key.

      Chords (guitar · MIDI)

      ⚠ Best-effort — may not be fully accurate. Chords are auto-detected from the MIDI notes (the files carry no chord data), so some songs — especially power-chord / pedal-tone arrangements — can read the wrong quality or root. Treat it as a guide. Follows the Key transpose · # sharps. Simplify collapses 7ths/sus and fixes power chords to the key's triad (e.g. E5→Em).
      🎤 Singing

      Pitch guide

      Reads the guide melody from the MIDI. Overlay + scoring need the mic on.
      Guide vocal (melody)
      Turn the melody up to learn a song, mute to perform, solo to isolate it.

      Microphone & voice

      Feedback & noise
      Best fix for feedback: use headphones. Echo-cancel + gate tame howl on speakers.
